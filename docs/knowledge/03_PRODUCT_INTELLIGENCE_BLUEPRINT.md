# Product Intelligence Blueprint

**Version:** 0.1. **Status:** canonical core.

Продукт решает конкретную бизнес-задачу быстрее, качественнее и с меньшими затратами, чем ручная работа или разрозненные инструменты. Функции добавляются только при подтверждённой ценности и не должны разрушать архитектурные границы.

Продукты остаются самостоятельными; общие компоненты выносятся только после подтверждённого повторяющегося паттерна. Порядок развития: проблема → результат → спрос → оплата → автоматизация → масштабирование.
