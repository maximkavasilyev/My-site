# Knowledge Constitution

**Version:** 1.0. **Status:** highest-level Knowledge OS rules.

Реальная проблема раньше технологии; результат раньше автоматизации; клиент платит за изменение результата. Факты, выводы и гипотезы разделяются, ограничения не скрываются, продукты самостоятельны, а общие компоненты появляются только при доказанном reuse.

Архитектура не должна превращать экосистему в монолит. Наблюдаемость и безопасность обязательны; репутация выше краткосрочной прибыли; медиа обслуживает продукты; конфликт не исправляется молча.
