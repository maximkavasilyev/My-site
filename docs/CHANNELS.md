# CHANNELS.md — Роли и правила каналов

> Статус: Operating standard  
> Версия: 1.0

## 1. Личный сайт

### Роль

- канонический архив;
- долговечные статьи;
- страницы «Обо мне», «Проекты», «Контакты»;
- точка доверия;
- переход к конкретным продуктам.

### Публиковать

- кейсы;
- архитектурные разборы;
- исследования;
- долговечные экспертные статьи;
- продуктовые материалы с ясным CTA.

### Не публиковать

- проходные новости;
- необработанные мысли;
- короткие статусы;
- материалы, зависящие от контекста одного дня.

## 2. Telegram

### Роль

- основной живой канал;
- личные рабочие наблюдения;
- промежуточные выводы;
- короткие кейсы;
- обратная связь.

### Форматы

- короткий тезис;
- рабочая заметка;
- мини-кейс;
- ссылка на полный материал;
- вопрос аудитории;
- обновление продукта с содержательным контекстом.

## 3. YouTube

### Роль

- глубокие объяснения;
- демонстрации продукта;
- разбор интерфейса;
- архитектурные схемы;
- история создания.

### Ограничение

Не вводить обязательный график до подтверждения спроса и устойчивого процесса.

## 4. Дзен

### Роль

- дополнительная дистрибуция статей;
- рекомендательный трафик;
- широкая русскоязычная аудитория.

### Правило

Адаптировать материал под площадку, не копировать механически.

## 5. LinkedIn

### Роль

- профессиональное позиционирование;
- архитектурные и продуктовые тезисы;
- связи;
- короткие кейсы;
- результаты.

### Язык

Русский — основной, пока основная аудитория русскоязычная.

## 6. VK

### Роль

- дополнительное присутствие;
- дистрибуция;
- личная страница.

Отдельное сообщество создаётся только при наличии самостоятельной функции.

## 7. MAX и WhatsApp

Использовать как:

- каналы связи;
- продуктовые каналы;
- уведомления;
- комьюнити, если появится реальная потребность.

Не превращать в ещё одну обязательную редакцию.

## 8. Pinterest

Использовать только для:

- схем;
- инфографики;
- визуальных карточек;
- долговечных визуальных материалов.

## 9. Приоритет каналов

На первом этапе:

1. Telegram
2. Личный сайт
3. Дзен / LinkedIn / VK как адаптация
4. YouTube после готовности процесса
5. Остальные — по конкретной функции

## 10. Решение о новом канале

Новый канал допускается, если:

- есть целевая аудитория;
- существует подходящий формат;
- понятно, откуда берётся контент;
- стоимость поддержки приемлема;
- канал не дублирует существующий без причины.
