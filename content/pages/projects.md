# Проекты

## Pro-leads

Pro-leads — сервис для поиска новых B2B-возможностей на основе данных государственных закупок.

**Кому полезен.** Тем, кто ищет потенциальных B2B-клиентов среди компаний, получивших государственные контракты.

**Задача.** Сократить ручной просмотр закупочных данных и найти организации, с которыми имеет смысл продолжить работу.

**Как работает сценарий.** Пользователь задаёт параметры выборки. Сервис помогает выделить компании, получившие контракты, и собрать структурированный список организаций.

**Результат.** Список потенциальных клиентов для дальнейшего анализа и контакта, а не большой массив исходных закупок.

**Граница применения.** Полученный контракт — повод изучить компанию. Он сам по себе не подтверждает её интерес к вашему предложению и не гарантирует продажу.

## Tender Audit

Tender Audit — сервис для анализа закупочной документации и подготовки технической части заявки.

**Кому полезен.** Поставщикам, которые изучают закупочную документацию и готовят техническую часть заявки.

**Задача.** Уменьшить объём ручного разбора документов и помочь не пропустить существенные требования и условия участия.

**Как работает сценарий.** Сервис помогает разобрать закупочную документацию: выделяет существенную информацию, указывает на потенциальные риски и формирует основу для подготовки технической части заявки.

**Результат.** Материал для дальнейшей проверки и подготовки заявки, с которым можно последовательно разобраться в требованиях заказчика.

**Граница применения.** Выводы нужно сверять с исходными документами. Окончательное решение об участии и содержание подаваемой заявки остаются за поставщиком.
