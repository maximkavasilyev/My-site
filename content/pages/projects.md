# Проекты

## Pro-leads

Pro-leads — сервис для поиска новых B2B-возможностей на основе данных государственных закупок.

Он помогает находить компании, которые уже получили государственные контракты и могут стать потенциальными клиентами. Вместо ручного анализа большого массива закупок пользователь задаёт параметры выборки и получает структурированный список организаций для дальнейшей работы.

Задача проекта — сократить время на поиск целевых компаний и превратить открытые закупочные данные в понятный инструмент для B2B-лидогенерации.

## Tender Audit

Tender Audit — сервис для анализа закупочной документации и подготовки технической части заявки.

Он помогает поставщику быстрее разобраться в требованиях заказчика, структуре документов и условиях участия. Сервис выделяет существенную информацию, помогает обнаружить потенциальные риски и формирует основу для дальнейшей подготовки заявки.

Задача проекта — уменьшить объём ручной работы с документацией, сократить вероятность пропуска важных требований и сделать подготовку к участию в закупке более последовательной.
